# AI 教程情报搜集

两段式可复用流程：
1. **搜集核验**：围绕指定 AI 产品/工具，找教程向长文与视频帖，用一手公开指标排序。
2. **白话交付**：科技/金融等情报简报用少术语写法，每条附「怎么理解 + 举一反三」。

可只跑搜集、只跑白话改写，或两者叠加。

---

## 第一部分：搜集与核验

### 使用时机

- 要「高曝光教程 / 长文 / 视频帖」清单（某 AI 产品、助手、模型或工具的用法玩法）
- 需区分形态（如 X Article vs 教程视频帖），带原文链接与公开曝光
- 需可复核、禁止猜测数字

不适用：私信/非公开分析、付费墙全文转载、编造曝光、无关提及凑数。

### 需要的输入

| 输入 | 说明 | 缺省时 |
| --- | --- | --- |
| 主题关键词 | 正式名 + 别名 | 必问 |
| 内容类型 | Article、视频帖等 | 默认 Article + 教程视频帖 |
| 语言/圈层 | 中/英/中英 | 默认中英 |
| 时间窗 | 最近 N 天或起止 | 优先近 30–60 天高曝光 |
| 条数 | 每类 Top N | 默认每类 5–10 |
| 排序键 | impression 优先 | 有则用 impression |
| 是否要白话分析 | 是/否 | 科技金融简报默认是；纯教程清单默认否 |

### 权限与工具

- X 公共读取：`search_posts_all`、`get_posts_by_ids` 等；估费 ≳ $0.25 或翻页先征得同意
- 可选网页/新闻交叉；外链 403 不删链
- 禁止猜私有数据、要 Bearer、浏览器绕过连接器登录

### 完整步骤

1. 锁定任务卡（别名、类型、语言、时间窗、条数、排序、是否分析）
2. 用 X 前先读平台指南
3. 设计 3–8 条 query（教程词 + `url:…/i/article` / `has:videos` + `-is:retweet`）；勿依赖会失效的 `min_faves`
4. 拉取并请求公开指标与媒体字段；关键帖 `get_posts_by_ids` 复核
5. 归类：Article（含 `/i/article/`）/ 教程视频 / 用户明确要的其他长帖
6. 筛选：去无关、纯转、非教程；重叠资源保留曝光最高并标注
7. 核验排序：只用公开字段；时间转用户时区
8. 按交付格式撰写；若要分析则进入第二部分
9. 自检验收

### 来源核验规则

- 一手公开字段才写数字；缺失写「API 未返回」，禁止用作者自述或点赞反推 impression
- 作者自述与 API 冲突以 API 为准
- 链接以 API status url 为准；可另附 Article 链
- 文末列 query 与字段可得性

### 搜集类交付格式（易扫读）

每条含：作者、时间、曝光、一句话要点、帖子/Article 链接；文末「数据说明」。

### 搜集验收 / 失败 / 审批

验收：类型分开；作者时间曝光内容链接齐全；无编造；主题确为教程向；有数据说明。

失败：工具未就绪按平台错误处理；额度高则缩小方案求确认；限流交付已得部分；零结果写清已试 query。

审批：范围不清、估费/翻页、扩平台、争议条目、对外代发。

---

## 第二部分：白话分析与举一反三

### 使用时机

- 科技大事、金融讯息等「讯息 + 理解」交付
- 用户要少术语、每条有分析、案例帮理解市场
- 可接在第一部分之后，或对已有核验条目做改写

只要清单/只要链接/明确不要评论时，跳过本部分。

### 步骤

1. 先写事实（数字只用来源里的）
2. 白话翻译官方说法
3. **怎么理解：** 谁受益/谁难受、主矛盾是什么
4. **举一反三：** 同机制历史或「同一新闻不同板块输赢相反」
5. 易扫读排版

### 写法规则

- 少术语；必用术语后括号补人话
- 每条：事实 → **怎么理解** → **举一反三**
- 案例须与机制同类，禁止硬凑
- 可讲影响与留意点；不编造数据、不给具体买卖指令或收益承诺
- 社媒当温度计，一手行情/官媒为准

### 白话交付格式

每条：白话标题与时间 → 事实要点 → 来源 → **怎么理解** → **举一反三**。

### 白话验收 / 失败 / 审批

验收：事实与分析分开；少术语；每条有理解+案例；无臆造、无下单指令。

失败：无来源不进正式条；影响不清不强行案例；用户只要事实则去掉分析。

审批：当投资建议或代发；点名买卖标的；未核验当确定事实——禁止。
